# MAVM. — Creative Technologist & Educator

Portafolio profesional de Maikel Andres Vinces Mendoza. La aplicación reúne docencia, inteligencia artificial, producto digital, audiovisual y arte visual en una narrativa común: “Transformo ideas complejas en experiencias visuales, educativas y digitales.”

## Ejecutar en local

Requisitos: Node.js 22+.

```bash
npm install
npm run dev
```

Abre `http://localhost:3000`.

## Desplegar en Vercel

Importa el repositorio en Vercel. El comando de build es `npm run build` y no se requieren variables de entorno en esta primera versión.

## Editar contenido

Los proyectos viven en `data/projects.ts`; herramientas en `data/tools.ts`; y trayectoria/principios en `data/experience.ts`. Los placeholders visuales abstractos pueden sustituirse por imágenes o videos reales en `components/ui/AbstractVisual.tsx`.

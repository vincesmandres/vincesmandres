Simulador: una imagen como matriz

Cada entrada de la matriz controla la intensidad de un píxel entre 0 y 255.

1. Edita la matriz de intensidades

G = [gij],   0 ≤ gij ≤ 255
[
]

Seleccione un valor y escriba un número entre 0 y 255. La imagen se actualiza inmediatamente.

2. Representación física: 3 × 3 píxeles

Seleccione un píxel para identificar su fila, columna e intensidad.
0 = negro
128 ≈ gris
255 = blanco

3. Comprueba lo aprendido

1. ¿Qué intensidad tiene el píxel de la fila 2, columna 3?
2. ¿Cuál es más oscuro: g₁₁ o g₃₃?
3. ¿Cuántos píxeles representa una matriz 3 × 3?
